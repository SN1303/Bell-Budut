Import Jadwal dari Excel

Unggah file Excel yang sudah diisi. Anda bisa memilih untuk memperbarui grup yang sudah ada atau membuat grup baru secara otomatis.

💡 Lebih Mudah: Cukup pilih nama lagu di Excel, sistem otomatis membaca kodenya.
💡 Panduan Pengisian Excel Pintar:

• Tidak Perlu Menghafal Kode Audio: Di Excel, cukup klik kolom 'Pilih Nada / Lagu Audio', lalu klik panah dropdown untuk memilih nama lagunya. Kolom 'Kode Audio' akan terisi sendiri otomatis via rumus VLOOKUP.

• Selalu Update Otomatis: Setiap kali Anda mengunggah lagu baru di tab Audio, template Excel yang diunduh akan otomatis menyertakan lagu baru tersebut di sheet referensi dan dropdown.

• Format Waktu: Gunakan format 24 jam JJ:MM (contoh: 06:55, 07:00, 12:30, 15:30).

• Hari Berlaku: Dapat dipilih: SEMUA, SENIN - JUMAT, SENIN, SELASA, RABU, KAMIS, JUMAT, atau SABTU.

Cadangkan Database (Backup)

Download salinan file SQLite (bell.db) yang memuat semua data grup, jadwal bel, konfigurasi audio, dan riwayat. Simpan di flashdisk atau Google Drive untuk keamanan.

Pulihkan Database (Restore)

Pulihkan data bel dari file cadangan sebelumnya. File database saat ini akan otomatis di-backup terlebih dahulu sebelum ditimpa demi keamanan.

Pemisahan Jalur Suara

Supaya suara YouTube / WA tidak bocor ke speaker sekolah

🔇 Bisukan Suara Notifikasi Windows ("Ting!", Error, Colok USB)
Mematikan bunyi "ting!" Windows agar tidak berbunyi mendadak ke speaker sekolah
💡 Cara Agar Bebas Nonton YouTube / Buka WA di Meja:
  1. Colok Headphone / Speaker Meja ke komputer untuk Anda sendiri (kabel ke Amplifier Bel Sekolah tetap tercolok di lubang speaker utama).
  2. Klik tombol "Buka Pengatur Suara Windows" di atas.
  3. Di jendela Windows yang terbuka, cari Google Chrome atau WhatsApp, lalu ubah Output-nya ke Headphone.
✓ Selesai! Sekali diatur, Windows akan mengingat setelan ini selamanya. Musik & WA hanya terdengar di telinga Anda!
